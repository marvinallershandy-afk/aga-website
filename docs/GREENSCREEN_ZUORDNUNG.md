# Greenscreen: Zuordnung Clip → Spieler

Noch kein Dreh verarbeitet. Diese Datei wird von `node scripts/greenscreen/build.mjs` (oder `--dry`)
überschrieben: je Clip erkannte Rückennummer, Methode, Spieler, Status (sicher / manuell / unsicher),
zugeordnetes Foto und die Zeitmarken der 7 Takes. Korrekturen: `scripts/greenscreen/zuordnung.json`,
Ablauf: [`GREENSCREEN.md`](GREENSCREEN.md).

Beispiel (synthetischer Test vom 05.10.2026): `shots-gs/gs-zuordnung-synthetisch.md`.
